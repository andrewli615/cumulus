# Decision records

Create one short Markdown file per material design choice, for example `0001-watch-only-or-companion.md`.

Template:

```markdown
# Decision: [title]
Date: [YYYY-MM-DD]
Status: proposed | accepted | revised

## Context
What requirement or experiment created this decision?

## Options
1. ...
2. ...

## Evidence and tradeoffs
Sources, device results, complexity, reliability, privacy.

## Choice
What was chosen, and why?

## Revisit when
What new evidence would change the choice?
```
